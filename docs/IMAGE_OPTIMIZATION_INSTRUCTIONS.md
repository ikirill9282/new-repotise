# Инструкция по оптимизации изображений на сервере

## Что было сделано

1. ✅ Улучшен `MediaOptimizer` - теперь всегда оптимизирует изображения для лучшего сжатия
2. ✅ Обновлена конфигурация - качество снижено до 60%, максимальный размер до 1200x1200px
3. ✅ Создана команда `images:optimize-all` для оптимизации всех существующих изображений
4. ✅ Все новые изображения автоматически оптимизируются при загрузке

## Что нужно сделать на сервере

### 1. Оптимизировать все существующие изображения

Запустите команду для оптимизации всех изображений на сервере:

```bash
cd /var/www/trekguider/project
php artisan images:optimize-all
```

**Параметры команды:**
- `--disk=public` - диск для оптимизации (по умолчанию: public)
- `--path=images` - путь к изображениям (по умолчанию: images)
- `--batch=50` - количество изображений в батче (по умолчанию: 50)
- `--force` - принудительная оптимизация уже оптимизированных изображений

**Пример с параметрами:**
```bash
php artisan images:optimize-all --batch=100 --force
```

**Важно:** 
- Команда покажет количество найденных изображений и попросит подтверждение
- Процесс может занять время в зависимости от количества изображений
- Команда показывает прогресс и статистику по завершении

### 2. Убедиться что очередь работает

Новые изображения оптимизируются через очередь. Проверьте что воркер очереди запущен:

```bash
# Проверьте статус воркера
php artisan queue:work --once

# Или запустите воркер в фоне (если используете supervisor/systemd)
# Проверьте конфигурацию supervisor или systemd для queue:work
```

### 3. (Опционально) Настроить автоматическую оптимизацию

Если хотите периодически проверять и оптимизировать новые изображения, добавьте в `app/Console/Kernel.php`:

```php
protected function schedule(Schedule $schedule)
{
    // Оптимизация новых изображений раз в день (в 3:00 ночи)
    $schedule->command('images:optimize-all --batch=100')
        ->dailyAt('03:00')
        ->withoutOverlapping();
}
```

## Устранение проблем

Если команда не работает:

1. **Если команда не найдена (`There are no commands defined in the "images" namespace`):**
   
   Команда теперь явно зарегистрирована в `bootstrap/app.php`. После обновления кода выполните:
   ```bash
   cd /var/www/trekguider/project
   git pull origin main
   composer dump-autoload
   php artisan config:clear
   php artisan cache:clear
   php artisan list | grep images
   ```
   После этого команда `images:optimize-all` должна появиться в списке.

2. **Проверьте права доступа:**
   ```bash
   chmod -R 775 /var/www/trekguider/project/storage
   chown -R www-data:www-data /var/www/trekguider/project/storage
   ```

3. **Проверьте что установлены зависимости:**
   ```bash
   composer install
   ```

4. **Проверьте логи:**
   ```bash
   tail -f /var/www/trekguider/project/storage/logs/laravel.log
   ```
