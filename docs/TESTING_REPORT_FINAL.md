## Оставшиеся проблемы

### 1. Проблемы с базой данных
**Проблема**: Некоторые тесты падают из-за отсутствия таблиц или проблем с внешними ключами
**Причина**: 
- User::created событие пытается создать user_options, но таблица может отсутствовать
- Некоторые миграции требуют дополнительных таблиц

**Решение**: 
- Использовать `User::withoutEvents()` для всех созданий пользователей (уже реализовано)
- Убедиться, что все миграции выполняются перед тестами
- Возможно, требуется настройка seeders для базовых данных

### 2. Проблемы с внешними сервисами
**Проблема**: Некоторые тесты требуют мокирования Stripe API
**Решение**: 
- Уже отключен Scout
- Требуется добавить моки для Stripe в тестах, которые создают заказы/платежи

### 3. Проблемы с представлениями
**Проблема**: Некоторые представления требуют данные, которые не создаются в тестах
**Решение**: 
- Добавить seeders для базовых данных (статусы, роли, категории)
- Или мокировать данные в тестах
