# Тестирование попапа сброса пароля

## Описание проблемы
Попап `reset-password-confirm` не работал из-за того, что Livewire пытался вызывать методы на родительском компоненте `Modals` вместо вложенного компонента `ResetPasswordConfirm`.

## Внесенные исправления

### 1. Исправлена привязка данных формы
- **Было**: Использовались кастомные JavaScript обработчики для обновления полей
- **Стало**: Используется стандартный `wire:model.live` для всех полей формы
- **Файл**: `resources/views/livewire/modals/reset-password-confirm.blade.php`

### 2. Исправлена отправка формы
- **Было**: Кастомный JavaScript для вызова метода `submit()`
- **Стало**: Стандартный `wire:submit.prevent="submit"` на форме
- **Добавлено**: `wire:key` на форме для правильной изоляции компонента

### 3. Добавлено отображение ошибок валидации
- Добавлены директивы `@error` для всех полей формы
- Ошибки отображаются как для `form.code`, так и для `code` (на случай разных форматов)

### 4. Добавлено логирование
- Логирование в методе `submit()` для отладки
- Логирование в JavaScript для отслеживания вызовов

### 5. Добавлен обработчик события как запасной вариант
- Метод `handleSubmitEvent()` в компоненте для обработки события `reset-password-submit`

## Инструкции по тестированию

1. Откройте страницу с формой входа
2. Нажмите "Forgot password?"

### Тест 3: Проверка валидации

## Отладка

### Если форма не отправляется:
1. Откройте консоль браузера
2. Проверьте логи:
   - `submitForm called` - функция вызывается
   - `Found via Livewire.find` - компонент найден
   - `Calling submit via component.call` - метод вызывается
3. Проверьте логи сервера на наличие записей `ResetPasswordConfirm::submit called`

### Если данные формы не сохраняются:
1. Проверьте консоль на наличие ошибок о несуществующих свойствах
2. Убедитесь, что используется `wire:model.live` на всех полях
3. Проверьте, что `wire:key` установлен на форме

### Если валидация не работает:
1. Проверьте, что ошибки отображаются через `@error` директивы
2. Проверьте логи сервера на наличие ошибок валидации
3. Убедитесь, что данные формы передаются в метод `submit()`

## Известные проблемы и решения

### Проблема: Метод вызывается на родительском компоненте
**Решение**: Использовать `wire:key` на форме для правильной изоляции компонента

### Проблема: Данные формы не синхронизируются
**Решение**: Использовать `wire:model.live` вместо кастомных JavaScript обработчиков

### Проблема: Ошибки валидации не отображаются
**Решение**: Добавить директивы `@error` для всех полей формы
