## Найденные проблемы и исправления

### 1. Проблемы с внешними сервисами
**Проблема**: Тесты пытались подключиться к Meilisearch и Stripe
**Решение**: 
- Отключен Scout через `SCOUT_DRIVER=null` в phpunit.xml
- Добавлена настройка в TestCase для отключения Scout

### 2. Проблемы с моделями
**Проблема**: Модели Order и Article не имели HasFactory trait
**Решение**: Добавлен trait и соответствующие импорты

### 3. Проблемы с фабриками
**Проблема**: Недостающие фабрики для тестирования
**Решение**: Созданы все необходимые фабрики

### 4. Проблемы с представлениями
**Проблема**: Некоторые представления требуют данные, которые не создаются в тестах
**Решение**: Требуется дополнительная настройка seeders или моков для тестов

## Команды для запуска тестов

```bash
# Запуск всех тестов
php artisan test

# Запуск только Unit-тестов
php artisan test --testsuite=Unit

# Запуск только Feature-тестов
php artisan test --testsuite=Feature

# Запуск Browser-тестов (Dusk)
php artisan dusk

# Запуск конкретного теста
php artisan test --filter=test_user_can_sign_in
```
