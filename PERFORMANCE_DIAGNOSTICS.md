# Диагностика производительности сайта

## Шаг 1: Проверка размера изображений на сервере

Выполните на сервере:

```bash
cd /var/www/trekguider/project

# Общий размер папки
du -sh storage/app/public/images/

# Количество больших файлов
find storage/app/public/images/ -type f -size +500k | wc -l

# Список больших файлов с размерами
find storage/app/public/images/ -type f -size +500k -exec ls -lh {} \; | awk '{print $5, $9}' | sort -hr

# Размеры отдельных файлов (первые 20)
find storage/app/public/images/ -type f -name "*.jpg" -o -name "*.png" -o -name "*.webp" | head -20 | xargs ls -lh
```

Это покажет:
- Общий размер папки с изображениями
- Количество файлов больше 500KB
- Список больших файлов с размерами
- Размеры отдельных файлов

**Ожидаемый результат:** 
- Большинство изображений должны быть меньше 500KB
- Большинство меньше 200KB
- Если есть файлы больше 500KB, их нужно оптимизировать дополнительно

## Шаг 2: Проверка логов сервера

```bash
# Логи Laravel (проверьте актуальную дату)
ls -la storage/logs/
tail -100 storage/logs/laravel-$(date +%Y-%m-%d).log

# Или все логи Laravel
tail -100 storage/logs/*.log

# Логи Nginx (если доступны)
tail -100 /var/log/nginx/error.log
tail -100 /var/log/nginx/access.log

# Проверка использования ресурсов
free -h
df -h
top -bn1 | head -20
```

## Шаг 3: Проверка производительности через браузер

1. Откройте сайт в Chrome/Firefox
2. Откройте DevTools (F12)
3. Перейдите на вкладку **Network**
4. Обновите страницу (Ctrl+R)
5. Проверьте:
   - Какие файлы загружаются дольше всего?
   - Какой общий размер страницы?
   - Сколько времени занимает загрузка?

6. Перейдите на вкладку **Performance** или **Lighthouse**
7. Запустите анализ производительности

## Шаг 4: Проверка кэширования

```bash
# Очистите кэш Laravel
php artisan cache:clear
php artisan config:clear
php artisan view:clear
php artisan route:clear

# Пересоздайте кэш
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

```bash

DB::enableQueryLog();
# Затем откройте страницу сайта
```

## Шаг 6: Проверка очереди

Если оптимизация изображений идет через очередь, проверьте воркер:

```bash

php artisan queue:work --once

# Или проверьте монитор очереди (если установлен)
php artisan queue:monitor
```

```bash
php artisan db:optimize
```

## Шаг 8: Проверка размера изображений в HTML

Проверьте, какие изображения загружаются на главной странице:

1. Откройте исходный код страницы (Ctrl+U)
2. Найдите все теги `<img>` и `<picture>`
3. Проверьте размеры изображений
4. Убедитесь, что используется `loading="lazy"` для изображений ниже сгиба

## Возможные проблемы и решения

### Проблема: Изображения все еще большие

**Решение:**
- Проверьте, действительно ли изображения оптимизированы (см. Шаг 1)
- Если есть файлы больше 500KB, запустите оптимизацию еще раз:
  ```bash
  php artisan images:optimize-all --batch=100 --force
  ```
  Теперь большие файлы (>500KB) будут оптимизированы более агрессивно:
  - Качество снижено до 50%
  - Максимальный размер уменьшен до 1000x1000px
- Возможно, некоторые изображения не были обработаны (WebP файлы без поддержки GD)
- Проверьте конкретные большие файлы и оптимизируйте их вручную, если нужно

### Проблема: Медленная загрузка из-за базы данных

**Решение:**
- Добавьте индексы в базу данных
- Используйте eager loading для отношений
- Оптимизируйте запросы

### Проблема: Медленная загрузка из-за PHP

**Решение:**
- Проверьте версию PHP (должна быть 8.2+)
- Увеличьте лимиты памяти в `php.ini`
- Используйте OPcache

### Проблема: Медленная загрузка из-за сервера

**Решение:**
- Проверьте использование CPU и памяти
- Убедитесь, что сервер не перегружен
- Рассмотрите возможность использования CDN

## Дополнительные оптимизации

### 1. Включите сжатие GZIP

Проверьте, что в nginx включено сжатие (уже должно быть в `docker/nginx/project.conf`).

### 2. Используйте CDN

Настройте CDN (Cloudflare, AWS CloudFront) для статических файлов.

### 3. Добавьте lazy loading для изображений

Убедитесь, что все изображения ниже сгиба имеют `loading="lazy"`.

### 4. Используйте WebP формат

Если браузер поддерживает WebP, используйте его вместо JPEG/PNG.

### 5. Оптимизируйте CSS и JS

Минифицируйте и объедините CSS/JS файлы.

## Контакты для диагностики

Если проблема не решена, соберите следующую информацию:

1. Результаты команд из Шага 1 и Шага 2
2. Скриншоты из DevTools (Network и Performance)
3. Логи Laravel
4. Версия PHP: `php -v`
5. Версия Laravel: `php artisan --version`
